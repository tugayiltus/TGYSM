# First release acceptance evidence

Acceptance criteria from `tgysm.md` §20, each mapped to the automated tests that prove it. Backend tests run against a real
PostgreSQL 17 database (`tools/test.sh`); E2E specs run on a fresh `tgysm_e2e` database at 360 px (`mobile-360`) and desktop
width (`tools/e2e.sh`).

- Test names are `Class.Method` (backend, xUnit) or `file › test title` (frontend Vitest / Playwright).
- Project prefixes: `Api` = `backend/tests/Tgysm.Api.IntegrationTests`, `App` = `backend/tests/Tgysm.Application.Tests`,
  `Dom` = `backend/tests/Tgysm.Domain.Tests`, `e2e` = `frontend/e2e`, `fe` = `frontend/src`.
- Commit `5163bfe` is the branch head the existing evidence was verified on; "Task 11" marks gap tests added with this table
  (commit `test: acceptance evidence for the first release`). Every Task 11 gap test passed on first run; each was proven
  meaningful by temporarily breaking the production code it guards (named in the evidence), seeing it fail, and restoring.
- Gates on the Task 11 tree: `tools/lint.sh` exit 0, `tools/test.sh` exit 0 (840 backend + 404 frontend tests, Domain +
  Application line coverage 95.5 %, frontend lines 90.8 %), `tools/e2e.sh` exit 0 (18 specs × 2 viewports).
