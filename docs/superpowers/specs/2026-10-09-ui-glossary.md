# UI Glossary (Turkish)

One word per thing in the Turkish UI (review UX-15). Enforced by `frontend/src/shared/i18n/glossary.test.ts`.

| Use | Do not use | Note |
|---|---|---|
| Lokasyon | Konum | Organization and asset location |
| IT | BT | IT staff, IT team |
| Bilgi bankası | Bilgi Bankası | Sentence case, like other titles |
| Nasıl Yapılır? | — | Only the home-page card that opens the knowledge base |
